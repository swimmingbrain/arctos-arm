# ROS 2 packages

| Package | Content |
|---|---|
| `arctos_description` | robot model (URDF, meshes, RViz), from ros2_arctos |
| `arctos_driver` | `arm_node`: joint states, trajectory execution, gripper, services |
| `arctos_moveit_config` | MoveIt 2 configuration, launch files, MoveIt client example |

Setup, interfaces and troubleshooting: [docs/ros2.md](../docs/ros2.md).
